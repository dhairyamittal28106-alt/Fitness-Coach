# Fitness Coach

React 19, TypeScript, and Vite browser fitness app with coaching, workout, nutrition, planning, posture, vision, and voice screens. Local AI features use RunAnywhere Web and MediaPipe Vision. Application is under Health-Fitness-Coach-main/.

    cd Health-Fitness-Coach-main
    npm install
    npm run dev

Use npm run build for a production build. Camera/microphone access may be needed; models may download on first use.
